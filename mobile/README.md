# DoSmart — отдельное Android-приложение

Пакет `kz.dosmart.shop`, без входа в Сойлефон и без доступа к его чатам.
Инструкция → каталог → корзина → ФИО, учреждение из списка и WhatsApp родственника → заявка в админке DoSmart.
Сотрудник магазина согласует состав, доставку и оплату с родственником. Отправка заявки не подтверждает оплату.

## Проверка и сборка

Нужны Flutter (проверено 3.47.3), Android SDK и Java, совместимая с Gradle 9.3.1.
Из этой папки:

```sh
flutter pub get
flutter analyze
flutter test
flutter build apk --debug --target-platform android-arm64 --dart-define=DOSMART_BASE_URL=https://dosmart.aican.cloud
adb install -r build/app/outputs/flutter-apk/app-debug.apk
```

Это тестовый APK с debug-подписью. Перед первой постоянной установкой настройте отдельный release keystore и release signingConfig в `android/app/build.gradle.kts`. Сохраните ключ вне Git: дальнейшие обновления требуют той же подписи. Не используйте ключ MDM для магазина.

`DOSMART_BASE_URL` должен быть HTTPS. Для приёма заявок сначала обновите бэкенд с `POST /api/v1/guest/orders`. Старый сервер сможет показать каталог, но не принять новую заявку.

## Поведение терминала

- Список товаров, цены и активные учреждения загружаются с DoSmart.
- Перед отправкой обязательны ФИО, учреждение, корректный формат телефона и согласие. Наличие WhatsApp у номера проверяет сотрудник.
- Сервер сам рассчитывает сумму, создаёт статус `new` / `unpaid`; доставка ещё не согласована.
- При неопределённом результате отправки форма блокируется, повтор использует тот же случайный UUID и те же данные.
- После успеха форма и корзина очищаются. После пяти минут бездействия или завершения сеанса очищается весь текущий сеанс. Персональные данные не записываются на диск.
- При закрытии процесса незавершённая попытка не сохраняется. Если подтверждение не получено, повторите отправку в текущем сеансе; не создавайте заявку заново без проверки у сотрудника.

Для киоска разрешите `com.soilephone.user` и `kz.dosmart.shop`. Используйте исходный Сойлефон без встроенного магазина. Обновлённый агент MDM показывает эту пару крупными плитками.
