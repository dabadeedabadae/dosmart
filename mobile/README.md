# DoSmart — отдельное Android-приложение

Пакет `kz.dosmart.shop`, без входа в Сойлефон и без доступа к его чатам.
Инструкция → каталог → корзина → ФИО, отряд, учреждение из списка и WhatsApp родственника → заявка в админке DoSmart.
Сотрудник магазина согласует состав, доставку и оплату с родственником. Отправка заявки не подтверждает оплату.

## Проверка и сборка

Нужны Flutter (проверено 3.47.3), Android SDK и Java, совместимая с Gradle 9.3.1.
Из этой папки:

```sh
flutter pub get
flutter analyze
flutter test
flutter build apk --debug --target-platform android-arm64 --dart-define=DOSMART_BASE_URL=https://dos-mart.kz
adb install -r build/app/outputs/flutter-apk/app-debug.apk
```

Это тестовый APK с debug-подписью. Перед первой постоянной установкой настройте отдельный release keystore и release signingConfig в `android/app/build.gradle.kts`. Сохраните ключ вне Git: дальнейшие обновления требуют той же подписи. Не используйте ключ MDM для магазина.

`DOSMART_BASE_URL` должен быть HTTPS. Для приёма заявок сначала обновите бэкенд с `POST /api/v1/guest/orders`. Старый сервер сможет показать каталог, но не принять новую заявку.

## Поведение терминала

- Список товаров, цены и активные учреждения загружаются с DoSmart.
- Перед отправкой обязательны ФИО, отряд, учреждение, корректный формат телефона и согласие. Наличие WhatsApp у номера проверяет сотрудник.
- Сервер сам рассчитывает сумму, создаёт статус `new` / `unpaid`; доставка ещё не согласована.
- При неопределённом результате отправки форма блокируется, повтор использует тот же случайный UUID и те же данные.
- После успеха форма и корзина очищаются. После пяти минут бездействия или завершения сеанса очищается весь текущий сеанс. Персональные данные не записываются на диск.
- При закрытии процесса незавершённая попытка не сохраняется. Если подтверждение не получено, повторите отправку в текущем сеансе; не создавайте заявку заново без проверки у сотрудника.

Для киоска разрешите `com.soilephone.user` и `kz.dosmart.shop`. Используйте исходный Сойлефон без встроенного магазина. Обновлённый агент MDM показывает эту пару крупными плитками.

## Личный кабинет: регистрация по ФИО и отряду (20.11.2026)

Для локальной проверки бэкенд должен слушать только loopback в режиме `APP_ENV=local` с `DOSMART_PRISONER_LOOPBACK_DEMO=true`. Для Android по USB используйте `adb reverse tcp:8091 tcp:8091` и debug-сборку с `DOSMART_BASE_URL=http://127.0.0.1:8091`.

- **Привязка планшета.** Сотрудник один раз вводит код учреждения из админки (Учёт лимитов → учреждение → «Планшеты учреждения»). Экран настройки открывается из кабинета, если планшет не привязан, или долгим нажатием на логотип. Токен привязки хранится в `tablet.json` (папка приложения) и отправляется заголовком `X-Dosmart-Tablet`. Новый код в админке отключает все старые привязки.
- **Вход и регистрация.** Человек пишет ФИО (слова в любом порядке, ё = е) и выбирает отряд, затем выбирает себя из списка. При первом входе задаёт пароль из 12 цифр (рекомендуем ИИН) или один из трёх контрольных вопросов. 5 ошибок — блокировка на 15 минут. Если под человеком зарегистрировался кто-то другой, сотрудник жмёт «Сбросить регистрацию» в карточке.
- **Кабинет.** Два блока (баланс и лимит месяца с переносом остатка), три кнопки: Магазин, Настройки, Выйти. Доставка в лимит не входит.
- **Настройки.** Смена пароля или вопроса (нужен текущий) и код для родственников из 6 цифр (всегда виден в настройках). Родственник вводит на `/family` фамилию и код, телефон помнит вход 30 дней. Новый код отменяет старый.

Для рабочего подключения маршруты `/api/v1/tablet*` и `/api/v1/prisoner/*` по-прежнему проходят через шлюз управляемых планшетов. Laravel сверяет заголовок `X-Dosmart-Tablet-Gateway` с `DOSMART_PRISONER_GATEWAY_SECRET`. `DOSMART_PRISONER_GATEWAY_INSTITUTION` теперь необязателен: учреждение берётся из привязки планшета. Если переменная задана, она должна совпадать с привязкой.

Локальная демонстрация: `php artisan db:seed --class=PrisonerDemoSeeder` (только `APP_ENV=local`).
- Код планшета: `20261120`.
- Отряд 7: «Демо Работающий Иванович» (не зарегистрирован, без лимита) и «Демо Неработающий Петрович» (пароль `000000000102`, норма 6 МРП).
- Отряд 3: «Демо Строгий Сергеевич» (вопрос о месте рождения, ответ «Кокшетау», 2 МРП).

Сборка и анализ Flutter падают из-за кириллицы в пути — копируйте `mobile/` в папку с латинским путём.
